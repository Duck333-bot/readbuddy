# ReadBuddy Private Alpha Checklist

## Objective

> Invite **20–30 active readers** to use one of their own challenging books for seven days. The learning goal is whether they return to continue the same book—not how many AI messages they send.

## Before invitations

| Gate | Evidence required |
|---|---|
| Core reader | Upload, page reading, persistent highlights, personal notes, bookmarks, table of contents, resume recap, and notebook work on desktop and mobile |
| AI safety | Real embeddings active; safe-mode retrieval blocks future pages; benchmark spoiler traps pass the release gate |
| Observability | Private `/alpha` dashboard records real reading opens, selection actions, saves, evidence taps, I’m Lost, debriefs, and Ask-this-book use |
| Privacy | Analytics stores interaction metadata only—never book passages, reader questions, or AI answers |
| Support | One contact route, clear known-limits note for scanned PDFs, and a rollback checkpoint are available |

## Alpha cohort

Recruit readers who are currently reading a difficult novel, nonfiction book, history, science, philosophy, or business book. Ask each person to upload a book they may use and to read normally for one week. Do not ask them to “try every feature”; that produces artificial behavior.

## The metrics that decide what comes next

| Signal | Decision it informs |
|---|---|
| Readers returning to the same book tomorrow and next week | Whether the core loop is worth deepening |
| Define + saved vocabulary usage | Whether to build flashcards |
| Debrief opens and follow-up interest | Whether to build chapter discussion |
| Explain → Simpler rate | Whether default explanation needs to become simpler |
| Evidence tap rate | Whether grounding is visible and trusted |
| I’m Lost rate | Whether navigation, context, or recaps are insufficient |

## Weekly review

Review the dashboard and five short user interviews. Fix the single biggest reading-flow or AI-trust problem first. Do not add a new feature family unless the data shows readers would miss it.
