# ReadBuddy — Color, Art, Graphics, Icons, and Minimalism Reset

## Goal

ReadBuddy should become **minimal but visually rich**. This does not mean adding more cards, decorations, gradients, or animation. It means fewer objects with stronger composition, clearer emotional color, original reading-native art, and a distinctive icon language.

The intended contrast remains deliberate: **outside the reader, ReadBuddy is expressive, colorful, and cinematic; inside the reader, it is quiet, typographic, and almost invisible.**

## Visual thesis

> A book is not a file. It is a small world that becomes more understandable as its earlier pages gather around the reader.

The signature artistic behavior is called **Memory Terrain**: soft color fields, cropped page fragments, notes, evidence coordinates, and one clear thread organize around a current passage. It is not a constellation, a technical network, a generic AI visualization, or decorative 3D art.

## Color system

| Role | Color | Job |
|---|---:|---|
| Paper | `#FFF8EE` | Warm foundation and calm reading-adjacent surface. |
| Deep Ink | `#18213D` | Type, quiet structure, and rare high-contrast anchors. |
| Periwinkle | `#AAB8F6` | Memory, earlier context, and soft structural fields. |
| Powder Blue | `#B9DAF2` | Open space, safety, and spoiler-aware distance. |
| Blush Rose | `#F3BEC9` | Human warmth, notes, and emotional emphasis. |
| Soft Mint | `#B7E2CC` | Resolution, comprehension, and finished connections. |
| Butter | `#F8D983` | Warm attention and bookmark moments. |
| Signal Coral | `#F4775D` | One active connection, never a general decoration. |

Color is always compositional. Each major scene combines paper with two soft fields and, at most, one signal-coral point. The system does not use dark navy as a default background, a rainbow of equal accents, generic purple gradients, or saturated neon.

## Art direction: Memory Terrain

Art is created from the material of reading itself: page fragments, margin notes, index-like marks, folded paper planes, a single passage in focus, coordinates, quiet surfaces, and evidence brackets. The images should feel editorial and slightly dreamy, but still modern enough for fiction, science, economics, and textbooks.

No imagery is borrowed from lifestyle advertising. There are no robots, AI brains, stock students, characters, blobs, floating fantasy objects, botanical arrangements, generic sparkles, or constellations.

## Four graphic primitives

| Primitive | Meaning | Shape rule |
|---|---|---|
| **Margin Thread** | One earlier connection matters now. | Single precise line, rounded end, signal coral only at the live point. |
| **Page Shard** | An earlier passage has been retrieved with its place intact. | Cropped paper rectangle with one deliberately torn or folded edge. |
| **Evidence Bracket** | The source and ReadBuddy’s help are distinct. | Open bracket with a small coordinate dot; never a full card border. |
| **Return Tab** | Help is temporary; reading resumes. | Folded tab or compact edge label that points back to the current page. |

## Custom icon direction

The icon family is **Margin Marks**: warm, slightly softened 1.75px line symbols with squared-yet-gentle ends, one optional color fill, and an evidence coordinate dot where appropriate. Each symbol should have a recognizable silhouette at 16px and 24px, but should never look like a generic software glyph or emoji.

| Product action | Icon metaphor |
|---|---|
| Explain | Evidence bracket opening around one line. |
| Simpler | One complex line becoming two calm, shorter lines. |
| Context | Margin Thread entering a Page Shard. |
| Who? | Name index tab with an evidence dot. |
| I’m Lost | Page edge with a small directional mark returning to a known point. |
| Evidence | Bracket plus coordinate dot. |
| Memory | Folded earlier page with a thread. |
| Book Brain | Four aligned page layers, not a brain icon. |
| Spoilers | Unread page receding behind a soft veil. |
| Notebook | Margin note folded into a small page. |

## Motion principles

| Motion | What it teaches | Rule |
|---|---|---|
| **Gather** | Relevant pieces of an earlier book page arrive near the current sentence. | 220–420ms; only the smallest useful evidence moves. |
| **Track** | The Margin Thread exposes why one passage matters. | One continuous line; no network growth. |
| **Reveal** | A Page Shard appears with its page coordinate. | Rise 8–16px with opacity; no bouncing. |
| **Recede** | Future material is unavailable in safe mode. | It softens and moves behind a paper veil. |
| **Return** | Help ends and attention returns to reading. | The Return Tab folds away or becomes a compact edge marker. |

All non-essential motion is removed under reduced-motion preferences. Scroll effects communicate a sequence; they do not create parallax decoration.

## Proposal board checklist

The founder review must include: a visual language board, a Margin Marks icon board, desktop and mobile three-scene landing concepts, desktop and mobile library concepts, desktop and mobile upload concepts, and desktop and mobile reader concepts. The reader must use the visual language only in small evidence moments and must not inherit high-density marketing color fields.

## Approval boundary

This is a proposal only. It authorizes no additional production redesign. Implementation begins only after a founder explicitly approves the system and identifies which visual elements have earned their complexity.
